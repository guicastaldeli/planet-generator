# ![logo](https://i.imgur.com/ZXZz77t.png)
Create totally custom planets in the solar system! 
This engine allows you to generate planets with custom 
- Shapes, 
- Textures 
- Colors 
- and more!... 
- up to 16 planets.

## How it Works:
Hovering your mouse over any planet you can:
- Select it
- View its name
- Delete it
- Simply take a closer look

### Controls
- Hold Left Mouse Button to move the Camera's position.
- Hold Right Mouse Button to move the Camera's look.
- Right Mouse Click on a planet opens the Planet Information.

### Presets
Presets are the main data of the planets, that includes:
- Shape
- Texture
- Color
- Orbit configuration
- Rotation Settings
- and more...

This allows you to easily share or load solar systems!.

### Control Panel
In the bottom-left corner, there's a **"C"** button:
![controls-button](https://i.imgur.com/GTNID7P.png)

Clicking it opens the **Control Panel**:
![controls-panel](https://i.imgur.com/6t7LRVZ.png)

##### Available Options:
- Generator: When clicked opens the planet generator.
- Import Preset: When clicked you can select a preset in **JSON** format and load it.
- Export Preset: Export a preset in **JSON** format.
- Save Preset: This saves the current preset as default.
- Reset to Default: Clears the current preset to the default preset.
- Clear: Clears everything and goes back to the default engine preset.
